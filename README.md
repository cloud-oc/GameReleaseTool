# GameReleaseTool

免费、自行持有源码的静态网页工具。无需账号、付费 API、构建步骤或运行时依赖。所有图片处理均在浏览器本地完成。

## 开始使用

1. 将整个文件夹放在同一个目录，用当前版本的 Chrome 或 Edge 打开 `index.html`。无需启动服务器。
2. 导入主视觉和 Logo。也可以先点击“使用测试图体验”。
3. 选择平台和展示位，拖动图片或用滑杆调整焦点、缩放及 Logo 位置。
4. 图标和截图需要分别上传独立图片。也可以给任意展示位指定独立图片。
5. 打开“检查与导出”，勾选需要的文件，修复阻塞项后下载 ZIP。
6. 定期“下载备份”。项目 JSON 包含原图、布局、规则和最近导出记录；“打开项目”可以恢复。

本地预览的浏览器与 `file://` 文件打开的浏览器具有不同的存储空间。需要迁移时请导出、导入项目备份，不要依赖浏览器缓存。

## 平台范围

- Steam：12 个展示位，包括商店胶囊图、库素材、两个图标、背景和一张截图。
- Epic Games Store：7 个展示位，包括 Offer 与库的横竖图、Logo、轮播截图、社交分享图。
- GOG：8 个官方模板画板尺寸，包括产品横幅、Logo、封面、背景、GALAXY 背景、网页图标、GALAXY 推广横幅、社交推广方图。
- itch.io：推荐封面尺寸，以及一个自定义工作尺寸的截图位。

这 47 个展示位不是完整的平台上架清单。需要多张截图时，用“管理规格 → 新增展示位”增加各张截图的槽位。程序不生成视频、PSD、ICO，也不会自动提交到商店后台。

## TapTap（v0.2 新增）
- 移动端：7 个展示位（5 类），含横版/方形宣传图、图标、编辑推荐图、3 张截图。
- PC：11 个展示位（9 类），含横竖封面、透明 Logo、库壁纸、宣传图、无 Logo 横竖图、图标、3 张截图。
- 参考 ReleaseCanvas 的分类，并用 TapTap 中国大陆开发者文档核对规格；不是国际版或小游戏规格。
- 旧项目首次打开自动补齐这两个平台，保留已有图片、裁剪、自定义规格和导出选择。已有同名平台由用户管理，不覆盖。
- 截图默认横屏。竖屏游戏可在管理规格中把三个截图位统一改为 720 × 1280。截图数量、方向、重复内容需人工核对；工具允许只导出部分素材。
- 无 Logo 槽位隐藏独立 Logo 图层，无法消除底图中已有的文字；透明 Logo 需要透明源图。
- 文件体积上限在实际编码后检查，超限会阻止交付；不自动压缩到指定大小。

## 扩展新平台

“管理规格 → 下载规则 JSON”，编辑 `platforms` 和 `specs`，再载入、应用。

最小示例见 `custom-platform.example.json`。它只有演示平台；直接应用会替换当前平台列表。实际扩展时，应把示例中的平台与展示位追加到下载的完整 JSON。

每个展示位有稳定的 ID、平台、尺寸、格式、素材类型、可选文件体积上限、规则说明和来源 URL。导入与修改后的规则标为“用户自定义”。待确认尺寸可将 `w` 与 `h` 同时设为 `null`，此时阻止导出。

- `kind: art` 使用全局主视觉，并可叠加 Logo。
- `kind: logo` 使用全局 Logo，保留比例，PNG 保留透明背景。
- `kind: icon / screenshot` 必须上传独立图片。
- `bounding: true` 仅用于 Logo：以 w/h 为最大边界，实际输出可小于其中一边。Steam 库 Logo 使用此模式。
- `noLogo: true` 不叠加独立 Logo；无法删除已经画在底图上的文字。
- `maxBytes` 为输出文件大小上限，以字节计。导出时检查实际编码结果。

## 检查与交付

阻止导出：缺少源图、尺寸未配置、实际生成文件超过指定体积上限。

警告：源图放大、未人工确认、建议尺寸或自定义规格、仅验证过画板尺寸的 GOG 预设。警告会记录到清单，不被当成自动通过。

ZIP 内有各平台目录、`manifest.json`、`READ-ME.txt`。清单记录实际像素、文件大小、SHA-256（浏览器支持时）、规则来源、警告和与上次导出的文件对比。ZIP 使用标准 STORE 容器，图片自身已按 PNG/JPG 编码。单张下载不附加清单。

## 已知边界

- GOG 尺寸来自官方 PSD 画板元数据，不是把整份 PSD 尺寸当作输出尺寸。尚未复刻原模板中的安全区、淡出、遮罩；PNG 是本工具的默认格式，必须按项目后台核对最终要求。来源与具体画板见 `SOURCES.md`。
- 不自动识别源图内文字、游戏标题、素材授权、内容合规或平台审核结果。三分线仅帮助构图，不是官方安全区。
- 使用浏览器 Canvas 解码和重新编码；输出请求 sRGB，但不提供专业 ICC 校验、CMYK 流程或色彩管理保证。
- Logo 透明度检测只做抽样提示，不能证明所有平台的透明度要求已满足。
- 单张输入限 30 MB / 6400 万像素；单张输出限 3200 万像素。大量高分辨率图片可能占用较多内存，可分批导出。
- 项目自动保存到 IndexedDB；浏览器可能清理数据，存储失败时会提示下载备份。备份含原始图片，可能较大。
- 规则核对日期为 2026-10-21，不会联网自动更新。平台变化后可自行编辑。
- 当前只有图片主视觉与 Logo 两层；不含任意文本编辑、多语言矩阵、多人协作与任意图层系统。

## 源码结构

- `index.html` / `style.css`：中文界面与响应式布局。
- `presets.js`：内置平台与规格。
- `core.js`：裁剪计算、规则校验、CRC32 与 ZIP。
- `engine.js`：图片渲染、PNG/JPG 编码、IndexedDB、SHA-256。
- `app.js`：项目、交互、检查与导出。

可以部署到任意静态托管，也可以一直离线使用。工具不会上传图片，不包含遥测或外部 CDN。
